# هوشیار AI — نسخه آماده انتشار سایت

این پروژه یک سایت چت فارسی واکنش‌گراست، همراه با سرور امن برای اتصال به سرویس هوش مصنوعی.

## مهم
- سایت هنوز آنلاین نشده است؛ این فایل‌ها آماده‌اند اما باید روی یک میزبان Node.js منتشر شوند.
- بدون تنظیم `OPENROUTER_API_KEY`، سایت در حالت آزمایشی پاسخ می‌دهد و هوش مصنوعی واقعی فعال نیست.
- کلید API را هرگز در `public/index.html` قرار ندهید. فقط در متغیر محرمانه محیطی میزبان وارد کنید.
- هزینه، محدودیت رایگان و شرایط سنی سرویس‌ها ممکن است تغییر کند. اگر ساخت حساب نیازمند حداقل سن یا رضایت والدین است، از والد/سرپرست کمک بگیرید.

## انتشار روی میزبان Node.js
1. کل فایل ZIP را در رایانه یا سرویس میزبانی بارگذاری کنید (ساخت پروژه باید از `package.json` و `server.js` پشتیبانی کند).
2. دستور build لازم نیست؛ دستور اجرا: `npm start`
3. نسخه Node.js را 18 یا جدیدتر انتخاب کنید.
4. در تنظیمات Environment Variables، در صورت داشتن کلید، مقدار `OPENROUTER_API_KEY` را اضافه کنید. اختیاری: `OPENROUTER_MODEL` و `SITE_URL`.
5. Deploy/Start را اجرا کنید و لینک HTTPS منتشرشده را باز کنید.
6. ابتدا بدون کلید، رابط سایت را آزمایش کنید. برای پاسخ‌های واقعی، تنظیم کلید API لازم است.

## اجرای آزمایشی روی رایانه
نیازمند Node.js 18+:
```bash
npm install
npm start
```
سپس `http://localhost:3000` را باز کنید.

## فایل‌ها
- `server.js`: سرور و مسیر API؛ کلید فقط در سرور خوانده می‌شود.
- `public/index.html`: رابط فارسی RTL، تاریخچه محلی، ذخیره گفتگو به txt.
- `package.json`: وابستگی‌ها و دستور اجرا.

## نکات حریم خصوصی
تاریخچه گفتگو در مرورگر همان دستگاه ذخیره می‌شود و با پاک‌کردن داده‌های سایت حذف می‌شود. این نسخه حساب کاربری/همگام‌سازی بین دستگاه‌ها ندارد. وقتی هوش مصنوعی متصل باشد، پیام‌های اخیر برای پاسخ به سرویس ارائه‌دهنده فرستاده می‌شوند؛ اطلاعات حساس را وارد نکنید.
